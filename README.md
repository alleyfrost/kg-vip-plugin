# 酷狗概念版自动签到 · EchoMusic 插件

打开 [EchoMusic](https://github.com/hoowhoami/EchoMusic) 后自动领取当天的酷狗概念版 VIP；应用一直运行跨天时也会自动补签，并在设置页显示 VIP 到期时间。

## 功能

- 启动自动签到：打开播放器后自动领取当天 VIP，无需手动操作
- 跨天自动补签：运行期间每天 0 点自动领取；电脑休眠或后台节流后，窗口重新激活时补查
- 已领取识别：当天已在 App 内领取时不会误报失败
- 每日去重：同一天最多自动执行一次；失败后当天不自动重试，可在设置页手动补签
- 状态面板：显示今日领取结果、VIP 到期时间、上次签到时间
- 自动开关：可随时关闭自动签到，不影响手动签到

## 环境要求

- EchoMusic `>= 2.2.6-beta.9`（在 macOS 2.3.0 上实测）
- 已在 EchoMusic 中登录酷狗账号
- 插件声明使用宿主内置的酷狗 API 能力，不需要自行部署服务或处理签名

## 安装

1. 下载或克隆本仓库。
2. 把 `manifest.json` 和 `index.js` 放到 EchoMusic 的插件目录：

   macOS：

   ```text
   ~/Library/Application Support/echo-music/plugins/kg-vip-checkin/
   ```

   Windows / Linux 请通过应用内的插件目录入口找到对应路径，目录名使用 `kg-vip-checkin`。

3. 重启 EchoMusic，在插件设置中启用「酷狗概念版自动签到」。

也可以在应用内打开插件目录后，直接新建 `kg-vip-checkin` 文件夹并放入上述两个文件。

## 使用

- 打开 EchoMusic 后会自动签到；当天已领取时会直接跳过。
- 在插件设置页可以：
  - 查看今日领取状态与 VIP 到期时间
  - 点击「立即签到」手动补签
  - 关闭 / 开启自动签到
- 应用跨天保持运行时，会在北京时间 0 点自动签到；窗口重新可见或重新获得焦点时会补查一次。

## 行为说明

- 日期统一按 `Asia/Shanghai` 计算。
- 签到流程为：领取当天 VIP → 尝试升级每日 VIP → 读取 VIP 到期时间。
- 当天已领取（接口返回 `131001` 等）按成功处理，并记录为「今日已领取」。
- 升级失败不影响当天领取结果，只会记录「升级未完成」。
- 自动签到每天最多一次；如果当天自动执行失败，可在设置页手动重试。

## 常见问题

**第二天没有自动签到？**

插件只在 EchoMusic 运行期间工作。应用未运行、或电脑整夜关机时不会签到；重新打开应用会自动补签，也可以在设置页手动签到。

**提示「升级未完成」或错误码？**

升级是附加步骤，失败不影响当天 VIP 领取。常见错误码如 `297000`、`297002` 通常表示当前没有可升级的奖励或已经升级过。

**提示登录已过期？**

在 EchoMusic 中重新登录酷狗账号即可。

**当天在手机 App 已经领取过，还会重复领吗？**

不会。插件会识别已领取状态并跳过，不会重复消耗领取次数。

## 隐私

插件不收集、不上传任何个人数据。所有请求均通过 EchoMusic 内置的酷狗 API 转发到酷狗服务器，登录凭证由 EchoMusic 管理。
